## 📋 项目简介

**SmartKBS** 是一款面向高中信息技术与通用技术课程的 AI 智能问答与教学管理平台。系统基于 **FastAPI + React** 构建，融合云端 AI 能力（阿里云 DashScope 与 DeepSeek），为教师和学生提供全方位教学辅助服务。

## ✨ 功能特性

### 📊 首页仪表盘

登录后进入智能首页，按角色聚合展示关键数据：

- **学生端**：待完成考试数、已完成考试数、累计积分与排名、活跃任务数、**待答测验数**、**已参与投票数**、近期考试成绩列表、系统公告、最近活动时间线（含测验/投票记录）、快速入口
- **教师端**：考试概览（草稿/已发布/已结束）、任务提交统计、学生总数、本周点名次数、**随堂测验总数与进行中数量**、**活跃投票数与回应人数**、任教信息、快速入口
- **管理员端**：教师数据 + 今日对话数 + 课堂互动概览、系统用户统计

### �💬 AI 对话

核心智能问答界面，支持流式对话、文件上传（图片/文档）、图像理解、文件摘要增强、历史记录检索、HTML 预览、多模型切换。

### 📄 资源中心

按用户目录浏览 HTML 教学资源文件，卡片网格展示，一键新标签页打开。
管理员/教师可在此**共享**自己的资源给其他用户：

- **管理员共享**：可选择「所有人」「指定教师（多选）」「指定年级（多选）/班级（多选）」
- **教师共享**：可选择「管理员和教师（多选）」+「自己的班级」，支持同时勾选
- 已共享的资源可随时取消共享

### 📁 资源管理

上传/删除/重命名教学资源文件（HTML/CSS/JS/图片/文档等），每位教师拥有独立资源目录，资源相互隔离。
每个文件支持**共享/取消共享**操作（与资源中心使用同一共享对话框）。

### 📚 资源分类导航

### � 消息通知系统

顶栏铃铛图标实时显示未读通知数量，支持：

- **自动通知**：资源分享时通知目标用户、考试发布时通知全体学生、提交考试后通知成绩
- **通知管理**：全部/未读筛选、标记已读、全部已读、删除
- **系统公告**：管理员/教师可发布带优先级（普通/重要/紧急）和置顶功能的公告
  - 支持按角色（全体/教师/学生）、年级、班级限定可见范围
  - 仪表盘展示最近公告，点击跳转到公告页面

### 👤 学生成长档案

聚合学生全维度学习数据，形成完整的成长画像：

- **五维数据总览**：考试成绩、课堂积分、点名记录、任务完成、AI 对话活跃度
- **成绩走势**：历次考试百分比趋势图
- **积分趋势**：积分变化时间线
- **成长时间轴**：按时间顺序展示所有学习事件（考试、积分变动、点名、任务提交）

> **学生查看自己，教师/管理员可查看任何学生**

### 🔬 AI 智能学情分析

利用 DashScope AI 对学习数据进行深度分析，生成自然语言学情报告：

- **班级学情总览**：选择年级/班级 → AI 自动分析 → 生成包含班级整体评价、学习亮点、薄弱环节、教学建议的报告
- **考试分析**：选择考试 → 展示逐题正确率统计表格 → AI 生成包含总体情况、分数分布、薄弱知识点、改进建议的报告
- **报告以 Markdown 格式呈现**，清晰结构化

> **教师和管理员可用**

### 🎯 课堂互动工具

随堂测验、快速投票、课堂提问三合一互动中心：

- **随堂测验**：
  - 教师通过**可视化编辑器**创建测验，支持**单选题、多选题、判断题**任意混合
  - 支持 AI 根据主题自动生成测验题目（单选/判断/混合）
  - 学生在线作答，自动评分（含多选题精确匹配），显示得分与正确率
  - 教师可查看每题正确率统计和参与学生列表
- **快速投票**：
  - 教师发起投票，支持**单选投票**和**多选投票**两种模式
  - 支持 AI 根据主题自动生成投票问题和选项
  - 多选投票实时统计各选项得票数和独立参与人数
  - 学生投票后实时查看结果（柱状图+百分比）
- **课堂提问**：
  - 学生可发起提问（支持匿名模式），教师直接在页面中回答
  - 支持 AI 辅助生成建议回答，教师可修改后提交
  - 提问仅**本班师生**可见，跨班隔离
- **班级权限**：
  - 学生只能看到同年级同班教师的测验、投票和同学的提问
  - 教师只能管理和查看自己班级学生的互动内容
  - 管理员拥有全部权限

> **所有用户可用，按角色和班级区分功能与可见范围**

### �📝 试题管理

AI 智能试题库系统，支持一键生成（按科目/题型/知识点/难度）与手动管理（编辑/删除/筛选），题型涵盖单选、多选、判断、简答。

### 📝 考试发布

完整在线考试系统，支持创建配置、智能/手动组卷、自动批改（客观题）、成绩查看与解析。

### ✅ 任务管理

教师发布学习任务，学生提交 AI 对话内容作为作业，支持查看提交详情、撤销提交、结束任务。

### 📥 文件中心

文件下载管理，支持上传/下载/删除，每位教师具有独立配额（默认 5GB）。
管理员/教师同样支持**共享下载文件**给其他用户（管理员→全员，教师→本班学生）。

### 👥 用户管理

完整的用户账号管理（注册、信息更新、密码修改、删除、CSV 导入），支持管理员/教师/学生三种角色。

### ⚙️ 系统配置

集中管理品牌信息、API 密钥（DashScope / DeepSeek）、模型参数、系统限制、下载配额等全局配置。

### 🏆 课堂积分

课堂积分激励系统，支持教师独立管理积分、排行榜、学生管理，多教师数据隔离，数据持久化至数据库。

### 🎯 点名管理

智能点名系统，支持公平加权随机抽取、权重自然衰减、轮次管理、历史记录追踪。
管理员可查看所有班级点名数据，教师仅查看自己班级。

## 🚀 快速开始

### 环境要求

- Python 3.9+
- Node.js 18+
- npm 或 yarn

### 1️⃣ 启动后端服务

```bash
# 方式一：直接启动
cd D:\SmartKBS
python backend/main.py

# 方式二：使用 Uvicorn 启动
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8086 --reload
```

后端服务默认运行在 `http://localhost:8086`

### 2️⃣ 启动前端开发服务器（可选）

```bash
cd frontend
npm install
npm run dev
```

前端开发模式默认运行在 `http://localhost:5173`

### 3️⃣ 默认管理员登录

| 用户名 | 密码 |
|--------|------|
| root   | root |

### 4️⃣ 配置 AI 服务

在 _系统配置_ 页面设置 DashScope API Key 或 DeepSeek API Key，或在 _系统配置 → API 密钥管理_ 中为每个用户单独配置。
