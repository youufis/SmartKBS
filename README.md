## 📋 项目简介

**SmartKBS** 是一款功能完备的全学段全学科通用 AI 智慧教学管理平台，专为中小学及高中教育场景设计。系统不限定任何特定学科，通过灵活的配置即可适配数学、语文、英语、物理、化学、生物、历史、地理、信息科技、通用技术、人工智能等任意学科的教学需求。

系统基于 **FastAPI + React** 构建，采用现代化前后端分离架构，深度整合阿里云
DashScope（通义千问/通义万相）与 DeepSeek 等大语言模型能力，通过灵活的 AI 调用服务
（支持知识库+大模型、百炼智能体应用、直接调用大模型三种模式，按「知识库 &gt; 智能体 &gt; 大模型」优先级自动接管），为师生提供一站式的智能化教学与学习体验。

**📦 三种部署方式**：Windows 桌面版一键安装（零环境，不需要 Python / Node.js）· 源码包部署 · Git 克隆部署（支持在线增量升级）。详见 [部署安装指引](#-部署安装指引)。

> 💡 **核心设计理念**
>
> - **🧠 AI Native 全场景注入**
>   AI 不是外挂工具，而是贯穿教、学、练、评、管的原生能力。
>   每一次对话、每一道试题、每一份报告都有 AI 深度参与，
>   却又让师生"感受不到 AI 的存在"，自然融入教学流程。
>
> - **🎯 因材施教 · 千人千面**
>   学生端 AI 学伴根据年级、知识薄弱点、学习习惯
>   动态调整对话风格与推荐内容；教师端 AI 助手
>   按任教班级、学科、时段提供精准的备课辅助与学情洞察。
>
> - **🔄 教学闭环 · 数据飞轮**
>   从学习行为采集 → AI 分析 → 个性化反馈 → 行为改善，
>   形成完整数据飞轮。每一次考试、练习、对话都在丰富
>   学生画像，反哺后续 AI 决策。
>
> - **⚡ 反浪费架构 · 零闲置 AI**
>   所有 AI 调用按需触发，无人访问不消耗任何资源。
>   每日精选池、热点新闻缓存、AI 摘要懒加载，
>   确保每一分算力都花在刀刃上。
>
> - **👥 角色感知 · 双轮驱动**
>   学生 → AI 学伴（陪伴式学习），教师 → AI 助手
>   （减负增效），管理员 → 全局智控。
>   三者各司其职，互不干扰。
>
> - **🏆 游戏化激励 · 内生驱动**
>   12 级称号系统 + 成就徽章 + 积分奖励引擎，
>   将学习过程转化为有成就感的成长旅程。
>   不靠外部压力，而靠持续的正反馈激发学习动力。
>
> - **🌐 学科无关 · 灵活适配**
>   任何学科、任意学段均可通过配置快速适配。
>   AI 提示词动态构建，无需修改代码即可切换课程体系。

- 底部标签栏固定 5 格：首页 / 学伴（教师为助手）/ 错题（教师为提问）/ 通知 / **菜单**，「菜单」打开当前角色全部可用功能

#### 📚 教学管理

### 📖 课程大纲（课程导学）

课程 → 章 → 节 → 知识点四级树形结构：

- **🤖 AI 智能生成**：粘贴文本或上传文件（txt/md/pdf/docx），AI 自动提取课程结构
- **✏️ 手动管理**：添加、编辑、删除课程/章节/知识点
- **🔀 拖拽排序**：同级和跨层级拖拽排序，灵活组织
- **🔗 资源绑定**：为知识点绑定 7 类资源（HTML 课件、下载文件、试题、考试、讨论、随堂测验、任务）
- **✅ 学习进度追踪**：学生逐知识点学习，标记完成状态，实时进度条
- **📊 课程进度总览（教师）**：全班学生知识点完成进度矩阵，按年级/班级筛选
- **🏋️ 课程练习**：教师一键为知识点生成 10 道单选题，学生在线作答

> **管理员/教师可管理；学生可查看并标记进度**

> **管理员/教师可出题；学生可参与练习**

### 💬 AI 对话（知识问答）

核心智能问答界面，基于 SSE 流式传输，提供流畅的 AI 对话体验：

- **⚡ 流式对话**：AI 实时逐字输出回复，即时反馈
- **📎 文件上传**：支持图片（JPG/PNG/GIF）和文档（PDF/Word/Excel/PPT/TXT/MD 等）
- **👁️ 图像理解**：上传图片调用视觉模型识别分析
- **🖼️ 多模态对话**：启用多模态后支持图片+文本同时输入，由多模态模型直接理解，无需文件摘要
- **📄 文件摘要增强**：自动对上传文档进行摘要，增强 AI 对话上下文
- **🔍 RAG 知识增强**：从试题库和课程大纲中检索相关知识，提升回答准确性
- **📜 历史记录**：自动保存并按会话标题显示，今天/昨天/按月分组，支持标题与正文搜索、悬浮预览、重命名与下载
- **👁️ HTML 预览**：对话中 HTML 代码块可一键预览
- **📋 示例提示词**：内置多个教学场景示例，一键填充
- **🎭 三种模式**：智答模式 / 学伴模式（学生）/ 助手模式（教师/管理员）
- **🎤 语音输入**：支持麦克风语音转文字输入
- **📷 拍照上传**：支持摄像头拍照直接上传

> **所有登录用户可用**

### 🧠 AI 学伴（学生专属）

AI 对话的智能升级模式，为学生提供个性化的学习陪伴体验：

- **👤 专属学习伙伴**：AI 学伴知道学生的姓名、年级、学习进度和薄弱知识点
- **🔄 三种人格切换**：
  - 🌟 **鼓励型**：温暖热情，充满正能量，多用鼓励用语
  - 📐 **严谨型**：严谨细致，注重分析"为什么错""怎么改"，举一反三
  - 😄 **幽默型**：风趣幽默，适度用梗和调侃让学习不枯燥
- **📊 学习画像侧栏**：实时显示称号、积分、薄弱知识点、考试趋势、连续学习天数
- **🔔 主动推送**：早安问候、考试结果分析、称号升级祝贺、学习提醒
- **💾 对话历史统一管理**：与智答模式共用聊天历史系统
- **⚙️ 自定义设置**：可自定义学伴名称、人格、开关学伴、每日唤醒时间
- **🎨 视觉差异化**：紫色学伴风格气泡与头像

> **学生可用（智答页面顶部切换）**

- **🎨 视觉差异化**：青绿助手风格气泡与头像

教师从错题本或知识点生成针对性练习题，推送至班级或指定学生：

- **🤖 AI 出题**：从错题本或知识点自动生成针对性练习题
- **📤 定向推送**：推送至班级或指定学生
- **✍️ 学生作答**：在线答题，支持选择题和简答题

#### 🔄 活动数据重置（清参与数据、留活动内容）

9 类活动（考试 / 智能练习 / 知识抢答 / 在线任务 / 随堂测验 / 代码练习 / 分组讨论 / 快速投票 / 课程练习）均提供"重置"入口：

- 🔧 **每日请求限额归位**：从「账号与安全」并入「AI 对话权限与每日限额」小节，谁能用与能用多少次放在一起；配置项与计数表全部不变，存量部署无需迁移
- 🧭 **模型候选集中一处、配置页改下拉**：对话 / 长文本 / 视觉 / 生图的可选模型统一到一份目录，配置页从手打文本框改成带说明的下拉（按推荐程度分组，清单外的模型名仍可直接填写）。此前模型名散在 18 个调用点，换一次默认值容易漏改，填了下线的模型也要等运行时才报错
- 🔎 **配置自检补齐**：生图与语音合成各加一个自检按钮，与既有的对话模型 / 智能体 / 知识库自检同口径。生图自检会回报实际走的通道与真正发出的尺寸，语音自检直接给一段可播放音频；两者限管理员并限次数，按钮旁注明会产生一次真实调用与少量费用
- 🖼 **生图两代通道自动分派**：新旧两代生图模型的调用通道、参数结构与尺寸规则都不同，旧代码只支持旧通道，而配置说明推荐的恰是新通道模型 —— 照说明改就全线生不出图。现在按模型自动路由，降级链也按各自通道重新装配参数；尺寸默认「自动」（不指定、由模型定），可选档位按每个模型的实测边界过滤，配错在保存时就拦下并写明规则
- 📊 **登录页访问统计**：原来只显示在线人数，现在补上今日访问（人数/人次）与累计次数。累计走一张**只增不减**的独立计数器 —— 管理员批量删除登录历史不会让这个数往回退（建档基线取当前留存条数，启用前已被删掉的历史追不回来，只偏低一次）。接口免登录、与登录页共用同一个 15 秒轮询并同频缓存，不给登录增加开销；统计写库失败只记日志，绝不拖垮登录
- 🗣 **语音合成加入第二代模型**：音色清单按模型分组（第二代自带方言与外语、英文音色更多），换模型时音色列表与默认音色自动跟着切。音色与模型不配对在保存时即拒绝（清单外手填的仍放行），运行时会回落本模型默认音色并留日志 —— 点名现场不会静默失声
- ⚡ **入口页不再被缓存**：入口 HTML 此前没有任何缓存指令，浏览器会沿用旧页面壳、一直跑旧的前端包，表现为"服务器已更新、管理员却看不到新功能"；现改为每次回源校验，发版后直接刷新即生效

不想装 Python 和 Node.js，就用桌面版安装包 —— 双击装完就能用。

2. 双击安装：简体中文向导，可自选安装目录，自动创建桌面与开始菜单快捷方式
3. 启动 SmartKBS：桌面版自动拉起内置后端，等 `8086` 就绪后自动打开应用窗口
4. 本机访问 `http://127.0.0.1:8086`；同一局域网内的学生访问 `http://本机局域网IP:8086`（如 `http://192.168.1.100:8086`）

| --- | --- |
| 运行依赖 | 无。目标机器不需要 Python / Node.js（Electron 壳 + PyInstaller 后端 + Vite 前端） |
| 数据存放 | `%APPDATA%\SmartKBS\`（数据库、上传文件、日志都在此），**卸载重装不丢数据** |
| 升级方式 | 下载新版安装包直接覆盖安装；桌面版不走「在线增量升级」（那是 Git 部署专属） |

## ❓ 常见问题

**Q: 忘记密码怎么办？**
A: 如果设置了密保问题，可在登录页点击「忘记密码」自助找回。否则请联系管理员在「用户管理」中重置密码。

**Q: AI 对话没有回复？**
A: 检查「系统配置」中是否已填写有效的 DashScope API Key。如已填写，检查 API Key 余额是否充足。

**Q: 文件上传失败？**
A: 文档最大 10MB，图片最大 5MB。请检查文件格式是否在白名单中。

**Q: 无法使用 AI 学伴/助手？**
A: 学伴模式仅学生可用，助手模式仅教师/管理员可用。请确认登录角色是否正确。

**Q: 考试无法提交？**
A: 检查是否在考试有效时间范围内，以及答题次数是否已用完。

**Q: 课堂积分未增加？**
A: 确认参与了支持积分的活动类型。积分在活动完成后自动发放，等级奖励需达到相应成绩百分比。

**Q: 如何升级系统？**
A: 1、管理员登录后，进入「系统配置 → 版本管理」，点击「检测更新」后按提示操作（仅 Git 部署支持）。
   2、下载最新源码 ZIP 包，解压覆盖原目录（保留 `backend/system_config.json` 和数据库文件），重启服务。
