## 📋 项目简介

**SmartKBS** 是一款功能完备的全学段全学科通用 AI 智慧教学管理平台，专为中小学及高中教育场景设计。系统不限定任何特定学科，通过灵活的配置即可适配数学、语文、英语、物理、化学、生物、历史、地理、信息科技、通用技术、人工智能等任意学科的教学需求。

系统基于 **FastAPI + React** 构建，采用现代化前后端分离架构，深度整合阿里云
DashScope（通义千问/通义万相）与 DeepSeek 等大语言模型能力，通过灵活的 AI 调用服务
（支持百炼智能体应用与直接调用大模型双模式），为师生提供一站式的智能化教学与学习体验。

> 💡 **核心设计理念**
>
> - **🧠 AI Native 全场景注入**
>   AI 不是外挂工具，而是贯穿教、学、练、评、管的原生能力。
>   每一次对话、每一道试题、每一份报告都有 AI 深度参与，
>   却又让师生"感受不到 AI 的存在"，自然融入教学流程。
>
> - **🎯 因材施教 · 千人千面**
>   学生端 AI 学伴根据年级、知识薄弱点、学习习惯
>   动态调整对话风格与推荐内容；教师端 AI 助手
>   按任教班级、学科、时段提供精准的备课辅助与学情洞察。
>
> - **🔄 教学闭环 · 数据飞轮**
>   从学习行为采集 → AI 分析 → 个性化反馈 → 行为改善，
>   形成完整数据飞轮。每一次考试、练习、对话都在丰富
>   学生画像，反哺后续 AI 决策。
>
> - **⚡ 反浪费架构 · 零闲置 AI**
>   所有 AI 调用按需触发，无人访问不消耗任何资源。
>   每日精选池、热点新闻缓存、AI 摘要懒加载，
>   确保每一分算力都花在刀刃上。
>
> - **👥 角色感知 · 双轮驱动**
>   学生 → AI 学伴（陪伴式学习），教师 → AI 助手
>   （减负增效），管理员 → 全局智控。
>   三者各司其职，互不干扰。
>
> - **🏆 游戏化激励 · 内生驱动**
>   12 级称号系统 + 成就徽章 + 积分奖励引擎，
>   将学习过程转化为有成就感的成长旅程。
>   不靠外部压力，而靠持续的正反馈激发学习动力。
>
> - **🌐 学科无关 · 灵活适配**
>   任何学科、任意学段均可通过配置快速适配。
>   AI 提示词动态构建，无需修改代码即可切换课程体系。

#### 📚 教学管理

### 📖 课程大纲（课程导学）

课程 → 章 → 节 → 知识点四级树形结构：

- **🤖 AI 智能生成**：粘贴文本或上传文件（txt/md/pdf/docx），AI 自动提取课程结构
- **✏️ 手动管理**：添加、编辑、删除课程/章节/知识点
- **🔀 拖拽排序**：同级和跨层级拖拽排序，灵活组织
- **🔗 资源绑定**：为知识点绑定 7 类资源（HTML 课件、下载文件、试题、考试、讨论、随堂测验、任务）
- **✅ 学习进度追踪**：学生逐知识点学习，标记完成状态，实时进度条
- **📊 课程进度总览（教师）**：全班学生知识点完成进度矩阵，按年级/班级筛选
- **🏋️ 课程练习**：教师一键为知识点生成 10 道单选题，学生在线作答

> **管理员/教师可管理；学生可查看并标记进度**

### 📚 课程练习（知识点练习）

基于课程大纲知识点的 AI 练习系统：

- **🤖 AI 自动出题**：教师为知识点一键生成 10 道单选题
  - AI 从题库智能搜索合并匹配题目
  - 差额由 AI 补全新题
  - 新题自动入库
- **✍️ 学生在线作答**：在课程学习页面点击知识点直接练习
- **🏆 自动积分奖励**：
  - 参与基础分：2 分
  - 优秀（≥90%）：+15 分
  - 良好（≥75%）：+10 分
  - 及格（≥60%）：+5 分
- **📊 数据展示**：首页看板展示完成数与平均正确率
- **📋 成长档案集成**：个人档案页集成练习明细

> **管理员/教师可出题；学生可参与练习**

### 💬 AI 对话（知识问答）

核心智能问答界面，基于 SSE 流式传输，提供流畅的 AI 对话体验：

- **⚡ 流式对话**：AI 实时逐字输出回复，即时反馈
- **📎 文件上传**：支持图片（JPG/PNG/GIF）和文档（PDF/Word/Excel/PPT/TXT/MD 等）
- **👁️ 图像理解**：上传图片调用视觉模型识别分析
- **🖼️ 多模态对话**：启用多模态后支持图片+文本同时输入，由多模态模型直接理解，无需文件摘要
- **📄 文件摘要增强**：自动对上传文档进行摘要，增强 AI 对话上下文
- **🔍 RAG 知识增强**：从试题库和课程大纲中检索相关知识，提升回答准确性
- **📜 历史记录**：自动保存，按日期浏览、树形查看、全文搜索
- **👁️ HTML 预览**：对话中 HTML 代码块可一键预览
- **📋 示例提示词**：内置多个教学场景示例，一键填充
- **🎭 三种模式**：智答模式 / 学伴模式（学生）/ 助手模式（教师/管理员）
- **🎤 语音输入**：支持麦克风语音转文字输入
- **📷 拍照上传**：支持摄像头拍照直接上传

> **所有登录用户可用**

### 🧠 AI 学伴（学生专属）

AI 对话的智能升级模式，为学生提供个性化的学习陪伴体验：

- **👤 专属学习伙伴**：AI 学伴知道学生的姓名、年级、学习进度和薄弱知识点
- **🔄 三种人格切换**：
  - 🌟 **鼓励型**：温暖热情，充满正能量，多用鼓励用语
  - 📐 **严谨型**：严谨细致，注重分析"为什么错""怎么改"，举一反三
  - 😄 **幽默型**：风趣幽默，适度用梗和调侃让学习不枯燥
- **📊 学习画像侧栏**：实时显示称号、积分、薄弱知识点、考试趋势、连续学习天数
- **🔔 主动推送**：早安问候、考试结果分析、称号升级祝贺、学习提醒
- **💾 对话历史统一管理**：与智答模式共用聊天历史系统
- **⚙️ 自定义设置**：可自定义学伴名称、人格、开关学伴、每日唤醒时间
- **🎨 视觉差异化**：紫色学伴风格气泡与头像

> **学生可用（智答页面顶部切换）**

- **🔔 消息通知**：发布/取消/修改/提前结束时自动通知

## 📦 部署安装指引

### 方式一：下载源码包部署（推荐新手）

1. 从 GitHub 下载最新源码 ZIP：[youufis/SmartKBS](https://github.com/youufis/SmartKBS)
2. 解压到服务器目录（如 `D:\SmartKBS`）
3. 安装 Python 依赖：

   ```bash
   pip install -r requirements.txt
   ```

4. 启动服务：

   ```bash
   python backend/main.py
   ```

### 方式二：Git 克隆部署（推荐，支持在线升级）

```bash
git clone https://github.com/youufis/SmartKBS.git
cd SmartKBS
pip install -r requirements.txt
python backend/main.py
```

### 在线升级系统（Git 部署专属）

如果通过 `git clone` 部署，系统升级全自动完成：

1. 管理员登录 → 系统配置 → **版本管理**
2. 点击「检测更新」，系统自动对比 GitHub 最新版本
3. 点击「增量升级」，自动执行：

   ```text
   git fetch（增量拉取差异代码）→ git reset（同步文件）
   → 数据库迁移 → pip 增量安装 → 重启服务
   ```

4. 升级失败自动回滚，进度实时显示

> **💡** 首次点击「增量升级」时，系统会自动执行 `git init` + `git remote add` 初始化本地仓库，无需手动配置即可享受在线升级。

### PIP 国内镜像加速

```bash
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

**Q: 忘记密码怎么办？**
A: 如果设置了密保问题，可在登录页点击「忘记密码」自助找回。否则请联系管理员在「用户管理」中重置密码。

**Q: AI 对话没有回复？**
A: 检查「系统配置」中是否已填写有效的 DashScope API Key。如已填写，检查 API Key 余额是否充足。

**Q: 文件上传失败？**
A: 文档最大 10MB，图片最大 5MB。请检查文件格式是否在白名单中。

**Q: 无法使用 AI 学伴/助手？**
A: 学伴模式仅学生可用，助手模式仅教师/管理员可用。请确认登录角色是否正确。

**Q: 考试无法提交？**
A: 检查是否在考试有效时间范围内，以及答题次数是否已用完。

**Q: 课堂积分未增加？**
A: 确认参与了支持积分的活动类型。积分在活动完成后自动发放，等级奖励需达到相应成绩百分比。

**Q: 如何升级系统？**
A: 1、管理员登录后，进入「系统配置 → 版本管理」，点击「检测更新」后按提示操作（仅 Git 部署支持）。
   2、下载最新源码 ZIP 包，解压覆盖原目录（保留 `backend/system_config.json` 和数据库文件），重启服务。
