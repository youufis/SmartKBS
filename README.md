# SmartKBS — 智慧教学平台

> **🌐 [中文](README.md) | [English](README.en.md)**
>
> **面向小学、初中、高中三个学段的 AI 智慧教学平台** — 学科、年级、班级均由配置驱动，**不限定任何一门学科**。
>
> 覆盖 **教 · 学 · 练 · 评 · 管** 五条主线，48 个功能分区按主线归为六章，共 50+ 功能点：
>
> - 🏠 **入口 · 首页与待办** — 智能仪表盘、学生待办清单
> - 🧑‍🏫 **教 · 教学与资源** — 课程大纲、AI 播客、AI 教学助手、智能题库、在线考试、智能组卷与 Word 导出、AI 资源推荐、AI 生成 HTML 资源、资源中心与管理、文件中心
> - 🎓 **学 · 学习与练习** — AI 对话（知识问答）、AI 学伴、课程练习、同步练习、错题巩固、每日精选与热点新闻、代码练习
> - 🎪 **练 · 课堂活动** — 随堂测验、课堂投票、提问管理、课堂抽问、课堂闯关、知识抢答、分组讨论、协作白板、智能点名与考勤、知识闯关、作业中心（对话 / 文件提交 + AI 自动批改）
> - 📊 **评 · 学情分析与激励** — AI 学情分析、AI 课堂总结、进度与活动监控、数据导出、成长档案、我的画像、12 级称号与成就徽章、自动积分奖励
> - ⚙️ **管 · 系统管理** — 用户与权限、系统公告、通知中心、技能管理、系统配置、在线增量升级、多主题外观

> 基于 **FastAPI + React** 构建，接入阿里云 DashScope（通义千问 / 通义万相）与 DeepSeek；SSE 流式输出与 WebSocket 实时链路支撑课堂并发，数据全部落在本地 SQLite 与本地目录，可完全离线部署。

## 项目简介

**SmartKBS** 把备课出题、课堂互动、练习考试、学情分析、荣誉激励和系统运维收敛在同一套账号体系与数据链路里，供一所学校、一个教研组或一位任课老师直接使用，无需拼装多个工具。

系统**不限定学科**。学科清单、年级、班级、题型、称号、AI 模型与提示词模板全部来自配置（`backend/system_config.json` 与数据库主数据表），切换课程体系只改配置、不改代码。平台自身就是从「人工智能」一门课起步、再泛化为多学科通用版式，因此「零学科硬编码」是落地结论而非宣传语。

系统内置**小学、初中、高中**三个学段的年级与班级主数据（一年级 ~ 高三，共 12 个预置年级），教师可持有「高一|高二」这样的多年级任教范围，所有数据读写按任教范围收口。幼儿与高校场景没有内置学段规则，需自行扩展年级主数据。

AI 能力经统一调用服务接入，支持三种模式，并按优先级自动接管、逐级降级：

1. **知识库检索增强（RAG）** — 知识库就绪时接管整条 AI 链路：先检索（百炼知识库，或本地题库与课程大纲），再基于命中文本生成，界面标注引用来源；检索失败自动降级到下一级
2. **百炼智能体应用** — 直接调用配置好的智能体应用
3. **直接调用大模型** — 兜底路径，兼容 DashScope 与 DeepSeek

> 📦 **三种部署方式**：Windows 桌面版一键安装（零环境，不需要 Python / Node.js）· 源码包部署 · Git 克隆部署（支持在线增量升级）。详见[部署安装指引](#deployment)。

## 核心设计理念

- **🧠 AI 原生，但题库优先**
  AI 嵌在出题、批改、答疑、分析、板书的具体环节里，而不是外挂一个聊天框；同时能靠已有数据解决的绝不重复调用模型——出题与组卷一律「题库优先 → 缺口交 AI → AI 生成的题必须入库留用」，让每一次算力消耗都沉淀成可复用的资产。
- **🎯 因材施教 · 千人千面**
  学生端 AI 学伴按自选人格（鼓励型 / 严谨型 / 幽默型）、连续出错的薄弱知识点与学习画像调整回答风格和推荐内容；教师端 AI 助手按任教范围与学科给出备课辅助与学情洞察。
- **🔄 教学闭环 · 数据飞轮**
  学习行为采集 → AI 分析 → 个性化反馈 → 行为改善构成闭环：考试、练习、对话、点名与抽问的数据回流成学生画像，画像再反哺下一轮的 AI 决策与推荐。
- **⚡ 按需调用，无人使用零消耗**
  所有 AI 调用按需触发：精选池用完才补、热点新闻缓存懒加载、AI 摘要不访问不生成、语音合成关闭即零计费。不为闲置算力付费。

**产品特性**

| 特性 | 落地方式 |
| --- | --- |
| 👥 三层角色，各配其 AI | 学生用 AI 学伴陪伴式学习，教师用 AI 助手减负增效，管理员掌握配置与督导，互不干扰 |
| 🏆 游戏化激励 | 12 级称号 + 成就徽章 + 自动积分奖励引擎，把外部压力换成持续正反馈 |
| 🌐 配置驱动 · 学科无关 | 换学科只改配置与提示词模板，无需修改代码 |
| 🔒 本地化优先 | 双 SQLite 库 + 本地目录存数据，可完全离线部署；AI 走国内可达通道，pip 有镜像方案，学生数据不出校 |
| 📱 零安装多端 | 手机浏览器直接访问，无需 App、无需额外部署 |
| 🖥️ 桌面版一键装 | Electron 壳 + 内置后端与前端产物，目标机器不需要 Python / Node.js |
| ⬆️ 在线增量升级 | Git 部署可站内完成拉取、迁移、依赖安装、重启，失败自动回滚 |

#### 手机端怎么用

- 底部标签栏固定 5 格：首页 / 学伴（教师为助手）/ 错题（教师为提问）/ 通知 / **菜单**，「菜单」打开当前角色全部可用功能

- 考试作答、抢答答题、闯关战斗是独立全屏页，选项按钮按触屏放大，倒计时与进度常驻顶部

### AI 播客（双主播对话）

为知识点一键生成**可以听的** HTML 播客页面：

- **🎚 时长可选**：3 / 4 / 5 分钟，默认 3 分钟；稿子字数按档位给（对话体约 250 字/分钟）
- **🧠 两种话题来源**：AI 依当前知识点给一批候选话题（可换一批），也可手动输入

- **📎 落地即资源**：生成的页面进「我的资源」，绑定到知识点后学生可直接打开收听（手机浏览器也能听）

- **🔁 状态回滚**：可选把活动状态退回「可重新参与」（如考试 已结束 → 已发布、知识抢答 进行中 → 等待中），不清内容
- **⌨️ 二次确认**：须原样输入活动名称；口令由服务端校验，直接调用接口也无法绕过
- **📩 学生告知**：可向受影响学生推送回执，回执按界面语言渲染（英文界面不残留中文）
- **🧮 积分口径**：回收该活动积分流水后立即重算受影响学生总分，与每日对账同口径，不做升级判定
- **🛡️ 权限**：管理员可重置全部（重置他人活动会在审计中标记为代操作）；教师仅能重置本人创建的活动，课程练习按「资源共享人 + 本人任教年级」双重判定；学生界面无入口且接口一律拒绝
- **📝 审计留痕**：每次重置都留下完整审计记录：操作者与角色、活动标识与名称、勾选项、删除明细与行数、回收积分、影响人数、通知人数、时间

> 所有活动类型共用同一套重置流程（选范围 → 预览 → 确认 → 审计留痕），新增活动类型自动获得同样的能力。

**安全**

- 📕 **错题本改成卡片式**：一道题按「题干 → 作答对照 → 解析 → 知识点」从上到下读完，配图紧跟题干、窄屏自动换行，不再撑破卡片

## 部署安装指引

### 方式一：一键部署 · SmartKBS 桌面版（零环境，最省事）

不想装 Python 和 Node.js，就用桌面版安装包 —— 双击装完就能用。

1. 下载最新安装包：[SmartKBS 最新版下载](https://github.com/youufis/SmartKBS/releases/latest)（自动跳最新 Release）
   （安装包命名形如 `SmartKBS-Setup-版本号.exe`，约 120 MB，**仅 Windows x64**）
2. 双击安装：简体中文向导，可自选安装目录，自动创建桌面与开始菜单快捷方式
3. 启动 SmartKBS：桌面版自动拉起内置后端，等 `8086` 就绪后自动打开应用窗口
4. 本机访问 `http://127.0.0.1:8086`；同一局域网内的学生访问 `http://本机局域网IP:8086`（如 `http://192.168.1.100:8086`）
   （首次启动请在 Windows 防火墙弹窗中选「允许访问」，否则其他设备连不上）

| 项目 | 说明 |
| --- | --- |
| 运行依赖 | 无。目标机器不需要 Python / Node.js（Electron 壳 + PyInstaller 后端 + Vite 前端） |
| 数据存放 | `%APPDATA%\SmartKBS\`（数据库、上传文件、日志都在此），**卸载重装不丢数据** |
| 升级方式 | 站内「系统配置 → 版本管理 → 检测更新」发现新版本后，下载新安装包覆盖安装（数据不丢）；桌面版不走 Git 方式的在线增量升级 |
| 端口 | 固定 `8086`。若这台机器已用 IIS 跑着 Web 版，先停掉，否则桌面版起不来 |
| 支持平台 | 目前只发布 Windows x64 安装包；macOS / Linux 的打包配置已就绪但暂未出包 |

### 方式二：下载源码包部署（需 Python 环境）

1. 从 GitHub 下载最新源码 ZIP：[youufis/SmartKBS](https://github.com/youufis/SmartKBS)
2. 解压到服务器目录（如 `D:\SmartKBS`）
3. 安装 Python 依赖：

   ```bash
   pip install -r requirements.txt
   ```

4. 启动服务：

   ```bash
   python backend/main.py
   ```

5. **升级**：登录后在「系统配置 → 版本管理」点「检测更新」。发现新版本会提示你下载最新源码包
   按上文替换（数据库、配置、上传文件都在原目录，不受影响）；若本机已装 Git，还可以点
   「一键转 Git 部署并升级」，把目录转成 Git 部署，之后即可站内一键增量升级。

### 方式三：Git 克隆部署（推荐学校机房，支持在线升级）

```bash
git clone https://github.com/youufis/SmartKBS.git
cd SmartKBS
pip install -r requirements.txt
python backend/main.py
```

### 在线升级系统（三种部署方式对照）

| 部署方式 | 升级方式 |
| --- | --- |
| 桌面版 | 站内「检测更新」→ 发现新版本 → 下载新安装包覆盖安装（数据在 `%APPDATA%\SmartKBS`，不会丢） |
| 源码包部署 | 站内「检测更新」→ 发现新版本 → 下载新源码包替换（数据库/配置/上传在原目录，不受影响）；本机已装 Git 时可「一键转 Git 部署」，之后享受站内增量升级 |
| Git 克隆部署 | 站内「检测更新」+「增量升级」全自动：fetch → reset → 数据库迁移 → pip 增量安装 → 重启，失败自动回滚 |

下面这条全自动流水线只对 **Git 克隆部署** 生效：

如果通过 `git clone` 部署，系统升级全自动完成：

1. 管理员登录 → 系统配置 → **版本管理**
2. 点击「检测更新」，系统自动对比 GitHub 最新版本
3. 点击「增量升级」，自动执行：

   ```text
   git fetch（增量拉取差异代码）→ git reset（同步文件）
   → 数据库迁移 → pip 增量安装 → 重启服务
   ```

4. 升级失败自动回滚，进度实时显示

> **💡** 首次点击「增量升级」时，系统会自动执行 `git init` + `git remote add` 初始化本地仓库，无需手动配置即可享受在线升级。

## 快速开始

**环境要求**

- Python **3.11+**（开发与打包实测版本 3.11.9）
- Node.js 仅在需要开发前端时安装；桌面版已内置全部运行时

### 步骤 1：启动后端服务

```bash
# 方式一：直接启动
python backend/main.py

# 方式二：使用 Uvicorn 启动（开发模式，热重载）
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8086 --reload
```

后端默认运行在 `http://localhost:8086`，并自动托管 `frontend/dist` 的前端产物，无需额外配置。

### 步骤 2：启动前端开发服务器（仅开发前端时需要）

```bash
cd frontend
npm install
npm run dev
```

前端开发模式默认运行在 `http://localhost:5173`，接口请求代理到后端。

### 步骤 3：以默认管理员登录

| 用户名 | 密码 |
| --- | --- |
| `root` | `root` |

> 🔑 首次登录后请立即修改密码并设置密保问题，避免默认凭据留在生产环境。

### 步骤 4：配置 AI 服务

进入「系统配置」填写 DashScope API Key（及可选的百炼知识库 / 智能体应用配置、DeepSeek Key）。配置页内置模型清单与连通性自检按钮，填完当场知道对不对。

未配置 AI 服务时，题库、考试、点名、资源、积分等主流程功能仍可使用，仅 AI 相关入口会给出明确提示。

<a id="faq"></a>

## 常见问题

- **忘记密码怎么办？**
  设置了密保问题的账号，可在登录页点「忘记密码」自助找回；否则联系管理员在「用户管理」中重置。
- **AI 对话没有回复？**
  先在「系统配置」确认 API Key 已填写且余额充足，再用配置页的连通性自检按钮验证；自检报错会指明是模型、知识库还是智能体应用的问题。
- **文件上传失败？**
  文档上限 10 MB、图片上限 5 MB（图片上限可在系统配置中调整），并需符合扩展名与内容白名单。
- **AI 学伴 / 教学助手打不开？**
  学伴仅学生可用，助手仅教师与管理员可用，先确认登录角色；教师还需在「用户管理」里配置任教年级与班级，否则AI 助手取不到教学范围。
- **考试无法提交？**
  检查当前时间是否在考试有效期内、答题次数是否已用完；卷面处于「有人在作答」状态时教师改题会被拒绝，这是锁卷保护。
- **课堂积分没增加？**
  只有支持积分的活动类型会在完成后自动发放，且设有每日封顶（可在系统配置调整）；教师与管理员不参与积分与榜单。等级奖励需要达到相应成绩百分比。
- **改了代码或升级后界面没变化？**
  先硬刷新（Ctrl+F5）；涉及 WebSocket、语音合成、AI 超时策略的改动需要**重启后端**才生效。
- **如何升级系统？**
  1. Git 部署：管理员登录后进入「系统配置 → 版本管理」，点「检测更新」再「增量升级」，失败会自动回滚；
  2. 源码包部署：下载最新 ZIP 覆盖原目录，保留 `backend/system_config.json` 与两个 `.db` 文件后重启；
  3. 桌面版：下载新版安装包直接覆盖安装，数据在 `%APPDATA%\SmartKBS\` 不会丢。
- **新机器装完起不来？**
  先确认 Python 为 3.11+，再核对依赖是否装全（`pip install -r requirements.txt`）；报错提示缺少模块时，优先检查该模块是否已在 requirements.txt 中。
