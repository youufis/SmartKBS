通用技术 · 模型或原型的制作

依据苏教版《技术与设计1》第六章及学业水平考试要求整理

一、模型与原型的概念

  • 模型：根据实物、设计图样或构思，按比例、形态或其他特征制成的与实物相似的物体。
  • 原型：在产品正式生产前制作的功能、尺寸与最终产品一致的实体，有时就是产品本身。
  • 关系：模型是原型的前期探索形式；复杂产品必须通过模型验证后才能投入原型试制。
【例】神舟飞船发射前使用缩比模型进行风洞试验；首艘量产车即为原型

二、模型的两大核心功能

  1. 使设计对象具体化
    模型可视、可触、可控制，能直观表达产品的比例、尺度、线型、色彩、材质等，是一种实体设计语言，便于设计者、委托方、生产单位沟通。
  2. 帮助分析设计的可能性
    对于高成本、大规模生产的产品，仅靠图纸难以验证可靠性。通过模型可提前发现结构、功能、人机等问题，避免重大经济损失。

三、不同设计阶段的模型类型

模型类型 用途与特点
草模 设计初期快速表达构思，形式简单，材料随意（如纸板、泡沫）
概念模型 在草模基础上，用概括手法表现造型风格、布局、人机关系等整体概念
结构模型 研究产品内部结构、连接方式、尺寸配合，常用于强度试验
功能模型 测试产品性能（如照明、承重）、人机交互，并检查组件配合关系
展示模型 采用真实材料、准确尺寸制作，与成品高度相似，用于市场宣传、方案审核
【教材案例】榨汁机：
• 草模：纸板拼接外形
• 功能模型：可模拟榨汁动作
• 展示模型：金属+塑料，外观逼真

四、材料的选择与规划

1. 常见材料分类

  • 金属材料：钢、铝、铜等，强度高但加工复杂
  • 无机非金属材料：陶瓷、玻璃
  • 有机高分子材料：塑料、橡胶、木材
  • 复合材料：碳纤维、胶合板

2. 材料选择原则

  • 满足功能与结构要求
  • 考虑加工工艺可行性
  • 控制成本与环保性
  • 兼顾美观与安全性

五、常用工艺类别

1. 木工工艺

  • 量具画线 → 锯割 → 刨削 → 钻孔 → 连接（榫接/钉接/胶接）→ 表面处理（打磨、上漆）

2. 金工工艺

  • 划线 → 锯割 → 锉削 → 钻孔 → 攻丝 → 连接（铆接/焊接）

3. 其他工艺

  • 塑料热弯、3D打印、激光切割、粘接等

注意：操作工具时必须遵守安全规范！

六、台灯模型制作实践（典型项目）

  1. 准备材料：木条、LED灯、电池盒、导线、开关等
  2. 选择工艺：木工（底座+支架）+ 电工（电路连接）
  3. 制作过程：按设计图下料 → 加工 → 组装 → 测试照明功能
  4. 反思优化：稳定性是否足够？开关是否方便？光线是否刺眼？

七、重要思考题（来自教材“学习反思”）

  • 设计过程的不同阶段是否都需要制作模型？
    → 不一定。简单产品可跳过某些模型；复杂产品需多阶段验证
  • 是否存在一种模型兼有各种模型的功能？
    → 展示模型最接近，但仍难完全替代功能/结构专项测试
