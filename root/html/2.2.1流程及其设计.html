1 认识流程

一、流程的含义

📌 教材定义

流程是一项活动或一系列连续有规律的事项或一种行为进行的程序。这些活动、事项或行为以确定的方式发生或执行，实现特定的结果。

简单来说，流程就是为了一定的目的去做事情的顺序。

💡 实例 · 回家开门

取钥匙 → 插入锁孔 → 旋转 → 开门。这是一个连续的、有顺序的活动，目的是打开房门。

二、流程的环节与时序

🔗

环节

将一项活动分解为若干个阶段或过程，每个阶段称为一个环节。

环节是相对的，可粗可细

⏱️

时序

环节之间的先后顺序。体现事物活动的内在规律。

有些时序不可颠倒

🔀

可调时序

有些环节的先后顺序可以调换。

"先扫地还是先拖地"

💡 制作小铁锤的流程

环节：下料 → 划线 → 锯削 → 锉削 → 钻孔 → 攻丝 → 淬火 → 电镀

时序：必须先"钻孔"才能"攻丝"，不可颠倒

💡 时序的不可颠倒性

"邮寄包裹"流程中，必须在"包装密封好"之后才"填写邮寄包裹单"，不可调换。

"打扫教室"流程中，"擦黑板"和"扫地"的时序可以互换。

流程环节时序 不可颠倒时序可调时序

2 流程的组成与描述

一、流程的组成要素

📌 两大要素

流程由环节和时序两部分组成。环节是流程中的具体活动或事项，时序是这些活动发生的先后顺序。

💡 实例 · 组装小电扇

环节：安装底座 → 安装支架 → 安装风扇头 → 安装扇叶 → 接通电源测试

时序：必须先安装底座才能安装支架

二、常用流程图表达方式

为了使流程的描述清晰可见，一般采用流程图来表达。常见表达方式：

环节名称 → 环节名称 → 环节名称
最简洁的流程表达形式，箭头表示时序方向。
开始 → 环节1 → 决策? → 环节2 → 结束
带判断分支的流程图表达。

三、流程的表达要求

📝

文字表达

用文字按顺序列出活动环节，适合简单流程。

签到 → 入场 → 开幕 → 演出

📊

图示表达

用方框、箭头等图形符号表示环节和时序，更加直观。

方框 = 环节，箭头 = 时序方向

3 流程的设计

一、流程设计应考虑的基本因素

🎯

目的与功能

流程要达到什么目标？完成什么任务？

⚙️

内在规律与机理

事物本身的内在规律决定了环节的划分和时序。

化学反应的先后次序

🧰

设备与材料

现有设备和技术条件能否支撑流程？

🔐

安全与环保

流程是否安全？是否对环境友好？

💰

成本与效率

流程是否经济高效？能否节省时间和资源？

二、流程设计的步骤

明确设计目标与任务

分析要解决的问题，确定流程期望达到的最终结果。

分解活动，划分环节

将整个过程分解为若干个可操作的阶段或步骤。

确定时序

明确各环节之间的先后关系，哪些可并行，哪些必须串行。

绘制流程图

用文字或图示方式表达流程设计结果。

评估与修改

审查流程是否合理、高效，修改不完善之处。

💡 设计实例 · 自动晾衣架钟点工流程

需求：设计一个流程，描述"自动晾衣架"的晾衣过程

环节划分：启动电机 → 晾衣架下降 → 挂上衣物 → 启动电机 → 晾衣架上升 → 锁定

不可颠倒的时序：必须先下降才能挂衣物，必须先挂好才能上升

流程设计划分环节确定时序 绘制流程图设计步骤

4 流程的优化

一、流程优化的目的

📌 核心目标

流程优化：在流程设计的基础上，对流程进行改进，以提高工作效率、降低成本、节约能源、提高质量、减少环境污染等。

二、流程优化的内容

⏱️

工期优化

通过并行执行某些环节，缩短总时间。

装修工程中水电与木工部分并行

💰

工艺优化

改进加工方法或工序，降低成本或提高质量。

3D打印替代传统注塑模具

🤖

技术优化

采用新技术、新设备替代旧有的环节。

自动焊接代替人工焊接

♻️

管理优化

改变管理方式，减少审批环节，提高效率。

网上审批代替纸质签批

三、流程优化的方法

🔀

改变时序

将串行改为并行，缩短整体时间。

流水线生产中合理安排工序并行

➕➖

增减或合并环节

消除不必要的环节，或将多个小环节合并。

合并入职体检与年度体检

🔄

改变环节顺序

调整某些环节的先后顺序以提高效率。

⚡

替代技术

用更高效的技术替代旧技术。

银行ATM取款代替柜台取款

💡 优化实例 · 快递分拣流程优化

优化前：人工分拣 → 逐个录入 → 分区堆放 → 装车。效率低、易出错。

优化后（技术优化 + 改变时序）：自动扫码识别 → 传送带自动分拣 → 直接到达装车口。环节减少，效率大幅提升。

💡 优化实例 · 小铁锤生产流程优化

优化前：每个环节都由一位师傅完成，逐个进行。

优化后（工期优化）：将淬火环节改为油淬（缩短冷却时间），将锉削改为砂带打磨（提高效率），将电镀工序外包（减少自制环节）。

流程优化工期优化工艺优化 技术优化管理优化并行工程
