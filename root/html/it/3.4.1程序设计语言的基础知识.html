程序设计语言的基础知识

一、程序设计语言概述

  • 定义：程序设计语言是人与计算机沟通的桥梁，是一组用于编写计算机程序的符号和语法规则。
  • 作用：将人类解决问题的思路转化为计算机可执行的指令序列。
  • 三大要素：
    • 语法（Syntax）：规定语言中符号如何组合成合法语句（如变量命名规则、语句结构）。
    • 语义（Semantics）：描述语句的实际含义和执行效果（如赋值操作的含义）。
    • 语用（Pragmatics）：反映语言在特定场景下的适用性（如Python适合教学，C++适合系统开发）。

二、程序设计语言的发展历程

  1. 机器语言
    • 由“0”和“1”组成的二进制代码。
    • 计算机可直接执行，效率最高。
    • 缺点：难读、难写、移植性差。
  2. 汇编语言
    • 使用助记符（如 ADD、MOV）代替二进制指令。
    • 需通过汇编器翻译为机器语言。
    • 优点：比机器语言易读；缺点：仍依赖硬件，移植性差。
  3. 高级语言
    • 接近自然语言或数学表达（如 Python、Java、C++）。
    • 需通过编译器或解释器转换为机器语言。
    • 优点：易学、易维护、可移植性强。

三、高级语言的两种执行方式

  • 编译型语言（如 C、C++）
    • 通过编译器一次性将源代码翻译为可执行文件（.exe）。
    • 运行速度快，但调试不便。
  • 解释型语言（如 Python、JavaScript）
    • 通过解释器逐行翻译并执行源代码。
    • 便于调试，但运行速度较慢。

四、程序的基本组成成分

  • 1. 数据成分
    • 常量：程序运行中值不变的量，如 45、'Hello'。
    • 变量：程序运行中值可变的量，由标识符（名字）和值组成。
      • Python 变量命名规则：
        • 由字母、数字、下划线组成；
        • 首字符不能是数字（如 s1 合法，1a 非法）；
        • 区分大小写（value ≠ Value）。
      • Python 是动态类型语言：变量无需声明类型，类型由赋值决定，且可动态改变。 
        a = 5       # a 是整数
print(a)    # 输出：5
a = 'ABC'   # a 变为字符串
print(a)    # 输出：ABC
  • 2. 运算成分
    • 包括算术运算（+、-、*、/）、关系运算（==、>、<）、逻辑运算（and、or、not）等。
  • 3. 控制成分
    • 控制程序执行流程的结构：
      • 顺序结构
      • 选择结构（if…else）
      • 循环结构（for、while）
  • 4. 传输成分
    • 数据输入输出（如 input()、print()）和赋值操作（=）。
  • 5. 函数
    • 实现代码复用和模块化。
    • 包括函数定义、声明和调用。

五、常见高级语言简介

语言 特点 典型应用
Python 语法简洁、动态类型、丰富的库 教学、数据分析、人工智能
Java 跨平台（JVM）、面向对象 企业级应用、安卓开发
C++ 高性能、支持底层操作 游戏开发、操作系统
JavaScript 浏览器原生支持、事件驱动 Web前端/后端开发

六、学习建议

  • 从 Python 入门，掌握变量、常量、基本数据类型和控制结构。
  • 理解“程序 = 数据结构 + 算法”的核心思想。
  • 通过实践项目（如“纪念品购买方案”）体验完整程序设计流程。
  • 重视调试能力：学会阅读报错信息（如 SyntaxError）。
