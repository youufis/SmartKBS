运用选择结构描述问题求解过程

适用教材：粤教版《信息技术 必修1：数据与计算》第四章 第3节

核心素养导向：计算思维、信息意识、数字化学习与创新

一、选择结构的基本概念

  • 定义：程序根据条件判断结果，选择执行不同代码路径的控制结构。
  • 生活类比：“如果下雨，就带伞；否则穿凉鞋”——基于条件做决策。
  • 作用：使程序具备“智能判断”能力，突破顺序结构的线性限制。

二、Python中选择结构的语法形式

1. 单分支结构（if）

if 条件表达式:
    语句块

特点：条件为真时执行，否则跳过。

2. 双分支结构（if-else）

if 条件表达式:
    语句块A
else:
    语句块B

特点：非此即彼，必执行其一。

3. 多分支结构（if-elif-else）

if 表达式1:
    语句1
elif 表达式2:
    语句2
elif 表达式N:
    语句N
else:
    语句N+1

特点：逐条判断，仅执行第一个为真的分支；若全假则执行else。

4. 嵌套if语句

在某个分支内部再使用if结构，用于处理更复杂的逻辑组合。

三、关键知识点解析

  • 条件表达式：返回布尔值（True/False），可包含比较运算符（>, <, ==, !=等）和逻辑运算符（and, or, not）。
  • 缩进规则：Python通过缩进标识代码块，同一层级必须对齐。
  • 执行流程：从上至下依次判断，一旦某条件成立，执行对应语句后跳出整个选择结构。
  • else子句可选：多分支中else不是必须的，但建议保留以处理未覆盖情况。

四、典型应用案例

案例1：购买笔记本最优方案（教材P82）

问题：用整数经费x元购买4元、5元、6元笔记本，要求全部花完且6元和5元本数最少。

x = int(input("输入经费的值(大于7的整数)："))
k = x // 4
y = x % 4
if y == 0:
    m = 0; n = 0
elif y == 1:
    m = 0; n = 1; k -= 1
elif y == 2:
    m = 1; n = 0; k -= 1
elif y == 3:
    m = 1; n = 1; k -= 2
print("6元的笔记本为：%d本" % m)
print("5元的笔记本为：%d本" % n)
print("4元的笔记本为：%d本" % k)

案例2：图书折扣计算

问题：同时购买A（3元）、B（5元）图书各n本，享8折，求节省金额。

n = int(input("请输入购买的图书A和图书B的本数均为:"))
a = 3 * n
b = 5 * n
y = (a + b) * 0.2
print("可节省的费用为: %.2f 元" % y)

（注：此例虽未显式用if，但隐含“是否同时购买”的选择前提）

五、常见误区与注意事项

  • ❌ 忘记冒号: → 语法错误
  • ❌ 缩进不一致 → IndentationError
  • ❌ 混淆赋值=与比较==
  • ⚠️ 多分支中条件顺序很重要，应按优先级或互斥性排列
  • 💡 建议：复杂条件可先用自然语言梳理逻辑，再转化为代码

六、核心素养落点

  • 计算思维：将现实决策问题抽象为条件判断模型，设计算法流程。
  • 信息意识：理解程序如何通过条件响应不同输入，体现智能化处理。
  • 数字化学习与创新：通过调试、优化选择结构程序，提升问题解决能力。

  2. 尝试将生活中的“如果…就…”场景转化为Python代码。
