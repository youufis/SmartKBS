算法及其描述 —— 知识纲要

一、算法的概念

定义：算法是解决一个特定问题所采取的确定的、有限的步骤。

  • ✅ 关键点：
    • 针对“特定问题”（如：规划从学校到长隆的路线）
    • 步骤必须“确定”（无歧义）且“有限”（能在有限步内结束）
  • 💡 示例：去北京颐和园旅游的算法步骤：
    1. 网上购买门票
    2. 购买火车票或机票
    3. 预订酒店
    4. 准备行李与票据
    5. 乘车前往北京
    6. 前往颐和园游玩
  • ⚠️ 注意：同一问题可能有多种不同算法（如不同交通方式组合）。

二、算法的五个基本特征

特征 说明 示例
1. 有穷性 算法必须在有限步内结束 判断抛物线与x轴是否有交点，最多执行4步
2. 确定性 每一步操作必须明确、无歧义 “若△≥0，则输出‘有交点’” 是明确指令
3. 输入 可以有零个或多个输入 计算绝对值需输入一个数；判断交点问题可无输入
4. 输出 必须有一个或多个输出 输出“有交点”/“无交点” 或 绝对值结果
5. 可行性 每一步都可在有限时间内完成 加法、比较、赋值等均为基本可执行操作

三、算法的描述方法

为了让他人或计算机理解算法，需用合适的方式进行描述。常用方法包括：

1. 自然语言描述

  • 使用日常语言（如汉语）描述步骤
  • ✅ 优点：通俗易懂，无需专门训练
  • ❌ 缺点：多分支或循环结构表达不清；存在歧义
  • 示例（苹果促销）：
    1. 输入苹果重量 x
    2. 若 x ≤ 3，则 y = 5x
    3. 若 x > 3，则 y = 5×3 + 5×0.6×(x−3)
    4. 输出应付款 y

2. 流程图描述

  • 用图形符号表示算法流程（起止框、处理框、判断框、流程线等）
  • ✅ 优点：直观、逻辑清晰，适合表达分支与循环
  • 常用于教学和程序设计初期

3. 伪代码描述

  • 介于自然语言与程序语言之间的结构化描述
  • 使用类似编程的语法（如 if...then, while...do）
  • 示例（绝对值）： 
    输入 x
If x ≥ 0 Then
    输出 x
Else
    输出 -x
End If

4. 程序设计语言描述

  • 用 Python、C++ 等语言编写可执行代码
  • ✅ 计算机可直接运行
  • Python 示例（求和）： 
    s = 0
for i in range(1, 101):
    s += i
print(s)

四、典型应用场景

  • 📍 出行规划：从A地到B地的最短/最快路径
  • 🛒 价格计算：超市折扣、阶梯电价等
  • 🅿️ 智能停车系统：
    • 传感器探测车位状态
    • 根据结果控制指示灯（空→绿，占→红）
    • 向控制器发送状态信息

五、核心素养关联

  • ✅ 计算思维：通过抽象、分解、模式识别设计算法
  • ✅ 数字化学习与创新：选择恰当方式描述并实现算法
  • ✅ 信息社会责任：理解算法在智能系统中的作用与影响
