信息科技 · 知识与智慧 知识纲要

一、核心概念体系

1. 数据（Data）

数据是现实世界客观事物的符号记录。
  • 未经处理的原始事实（如数字、文字、图像、声音等）
  • 本身无意义，需经加工才能产生价值
  • 例：温度计读数“25”只是一个数值

2. 信息（Information）

信息是经加工处理的、具有意义的数据。
  • 赋予上下文和解释后的数据
  • 可帮助人们理解现象或做出判断
  • 例：“今日气温25℃，适宜外出”——数据被赋予语境

3. 知识（Knowledge）

知识是人们对获取或积累的信息进行系统化提炼、研究和分析的结果，能精确反映事物的本质。
  • 来源于实践，又高于实践
  • 具有结构性、规律性和可迁移性
  • 例：欧姆定律 $I = \frac{U}{R}$ 是对大量电学实验数据的抽象总结

4. 智慧（Wisdom）

智慧是为了达到预定目标而运用知识解决问题的创新思维能力。
  • 强调应用、判断与创造
  • 体现为在复杂情境中做出合理决策
  • 例：设计一个智能台灯，根据环境光自动调节亮度，融合传感器、控制逻辑与用户需求

四者关系：数据 → 信息 → 知识 → 智慧，逐层递进，前者是后者的基础，后者是前者的升华。

二、知识发现路径

  1. 做实验：观察自然或技术现象
  2. 获取观察数据：通过仪器、传感器或人工记录
  3. 分析处理数据：使用图表、统计、编程工具（如 Python）
  4. 推理建立数学模型：归纳规律，形成公式或算法
  5. 实验验证模型：检验模型的准确性与普适性
  6. 形成知识：纳入已有知识体系
  7. 应用知识解决问题：实现从知识到智慧的跃迁

▶ 典型案例：欧姆定律的发现与应用（控制变量法 + Python 数据采集）

三、数字化学习与智慧发展

1. 数字化学习定义

通过数字化工具和资源开展的学习活动，具有灵活性、个性化与高效性。

2. 主要形式

  • 在线学习 / 远程学习
  • MOOCs（大规模开放在线课程）
  • 微课程、短视频教学
  • 游戏化学习
  • 基于项目的学习（PBL）

3. 优势

  • 突破时空限制
  • 支持个性化路径
  • 促进协作与探究
  • 借助 VR/AR/AI 提供沉浸式体验

4. 与智慧的关系

数字化工具不仅是知识传递媒介，更是智慧生成的催化剂——通过模拟、建模、数据分析等，帮助学生从“知道”走向“会用”“会创”。

四、教学与素养导向

  • 紧扣信息科技学科核心素养：信息意识、计算思维、数字化学习与创新、信息社会责任
  • 倡导基于项目的学习（PBL）：如“运用数字化工具探究生物/地理/化学知识”
  • 强调从知识记忆到智慧应用的转变
  • 评价关注过程与成果并重（参考教科书附录2“项目活动评价表”）
