数据及其特征

——高中信息技术必修一 · 第一章第一节

一、什么是数据？

数据是现实世界客观事物的符号记录，是信息的载体，也是计算机加工的对象。

核心定义：

  • 数据是对客观事物（如身高、体重、温度、速度等）的符号化表示。
  • 在计算机科学中，数据是所有被计算机识别、存储和处理的符号的总称。
  • 数据本身没有意义，只有在特定情境下对实体行为产生影响时才转化为信息。

常见数据形式：

  • 数值型：如 180 cm、70 kg、36.5℃、120 km/h
  • 非数值型：
    • 文本（文字、数字、字符）
    • 图形与图像
    • 音频
    • 视频

二、数据的特征

特征 说明 示例
多样性 数据可表现为多种形式（数字、文字、图像、声音等） 一段视频包含图像、声音、时间戳等多种数据
可记录性 数据可通过符号系统被记录和保存 结绳记事 → 纸质档案 → 数字存储
可加工性 数据可被采集、存储、传输、计算和转换 原始传感器数据 → 清洗 → 分析 → 可视化图表
依附性 数据必须依附于某种载体存在 文字依附于纸张或屏幕；声音依附于声波或数字文件
无意义性（原始状态） 孤立的数据本身不具意义，需结合上下文 “99” 可能是分数、价格、温度或学号

三、数据与信息的关系

基本关系链：

数据 → 信息 → 知识 → 智慧

  • 数据：原始符号记录（如：180）
  • 信息：经过加工处理、具有意义的数据（如：“小明身高180 cm”）
  • 知识：对信息的归纳、总结和应用（如：“成年男性平均身高约175 cm，180 cm属于偏高”）
  • 智慧：基于知识的判断与决策能力
“信息是经过加工处理的、具有意义的数据。”
——《信息技术 必修1：数据与计算》

四、数据在计算机中的表示

  • 所有现实世界的符号（文字、图像、声音等）均可被转换为二进制数（0 和 1）。
  • 计算机通过二进制进行逻辑运算，再将结果转换为人可感知的形式（视觉、听觉等）。
  • 例如：十进制数字 180 在计算机中以二进制 10110100 形式存储。

五、典型生活实例

  1. 健康监测：智能手环采集心率（数据）→ 分析是否异常（信息）→ 建议就医（知识应用）
  2. 交通导航：GPS定位坐标（数据）→ 计算最优路线（信息）→ 实时避堵（智慧服务）
  3. 社交媒体：用户点赞数（数据）→ 推荐热门内容（信息）→ 平台优化算法（知识沉淀）

六、学习提示（新课标核心素养导向）

  • ✅ 信息意识：能区分数据与信息，理解其价值
  • ✅ 数字化学习与创新：尝试用数字工具记录和分析身边的数据
  • ✅ 计算思维：思考数据如何被计算机处理
  • ✅ 信息社会责任：认识数据隐私与安全的重要性
