运用循环结构描述问题求解过程

一、循环结构的基本概念

  • 定义：程序中重复执行一段代码的控制结构，用于处理具有重复性特征的问题。
  • 生活类比：“每天早读10分钟”“打印100份试卷”——自动化完成重复任务。
  • 作用：避免冗余代码，提高程序效率和可维护性。

二、Python中循环结构的类型与语法

1. for 循环（遍历型循环）

for 变量 in 序列或range():
    语句块

特点：适用于已知循环次数或遍历集合（如列表、字符串、range对象）。

2. while 循环（条件型循环）

while 条件表达式:
    语句块

特点：在条件为真时持续执行，适用于未知循环次数但有明确终止条件的场景。

⚠️ 注意：必须确保循环体内能改变条件表达式的值，否则会陷入死循环！

三、range() 函数详解

常用于生成整数序列，配合 for 循环使用。

  • range(stop)：从 0 到 stop-1（默认步长1）
    例：range(5) → [0,1,2,3,4]
  • range(start, stop)：从 start 到 stop-1
    例：range(1,6) → [1,2,3,4,5]
  • range(start, stop, step)：指定步长（可为负数）
    例：range(2,11,2) → [2,4,6,8,10]
    例：range(10,0,-2) → [10,8,6,4,2]

四、循环控制语句

  • break：立即终止整个循环，跳出循环体。
  • continue：跳过本次循环剩余语句，直接进入下一次循环。
  • pass：空语句，用于占位（语法需要但无操作时）。
for letter in "Python":
    if letter == 'h':
        continue
    print("当前字母 :", letter)
# 输出：P y t o n

五、典型应用案例

案例1：累加求和（1+6+11+…+101）

s = 0
for i in range(1, 102, 5):  # 步长为5
    s = s + i
print(s)

案例2：阶乘计算（1×2×3×…×10）

s = 1
for i in range(1, 11):
    s = s * i
print(s)

案例3：while 循环实现倒计时

n = 5
while n > 0:
    print(n)
    n -= 1
print("发射!")

六、常见误区与注意事项

  • ❌ range(1,5) 不包含5 → 结果是1~4
  • ❌ while 循环忘记更新循环变量 → 死循环
  • ⚠️ for 循环变量在循环结束后仍保留最后一次值
