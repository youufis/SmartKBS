认识系统

🌐 系统的概念

由两个或两个以上相互联系、相互作用的要素所组成的具有特定功能和结构的整体。

人体（消化、呼吸、循环）· 学校（教师、学生、课程）· 计算机（CPU、内存、硬盘、系统软件）

📊 系统的特性

01

整体性（最核心）

系统整体功能 > 各要素功能之和

"三个臭皮匠，顶个诸葛亮"
02

相关性

要素之间相互联系、相互作用、相互依赖

手机摄像头、屏幕、芯片、电池——任何一个出问题，拍照功能都受影响
03

目的性

系统都具有特定的功能和目标

04

动态性

系统是动态发展的，随时间变化

城市系统随人口和经济发展而变化
05

环境适应性

系统能适应外部环境的变化

变色龙适应环境变色

📌 经典分析：自行车系统

子系统：传动、制动、转向、承载

要素间关系：车闸失灵→整个骑行系统功能受损

体现了整体性和相关性

📌 系统分析原则

  • ✦ 整体性原则 — 着眼整体
  • ✦ 科学性原则 — 有据可依
  • ✦ 综合性原则 — 多角度权衡

无汞、可回收

技术规范

照度≥300lx

系统设计就是在这些相互制约的需求中找到最佳平衡点
⟐ NODE.04

系统的优化

📈 目标

  • ⚡ 提高整体性能
  • 💰 降低运行成本
  • 🔄 增强系统稳定性

⚙️ 约束条件

  • 📐 不可变动的核心要素
  • 🔧 现有技术条件
  • 💰 可投入的资源
  • 📋 法规和安全规范

📌 经典优化

🚌 公交线路优化

问题：线路重复，运力浪费
优化：合并重叠线路、增设换乘枢纽
效果：整体效率提升，乘客等待时间缩短

💻 学校选课系统

问题：选课拥堵，系统崩溃
优化：服务器集群+分时选课+排队机制
效果：系统整体稳定性大幅提高
