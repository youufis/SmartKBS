第一章 走进技术世界

第一节：技术的发展

一、学习目标

  • 通过活动体验和案例分析，感悟技术的历史发展给人类社会带来的变化。
  • 畅想技术的未来，形成对待技术的积极情感和理性态度。
  • 理解“技以载道、技道融合”的技术哲学内涵。

二、核心内容

1. 技术发展的历史脉络（任务一：追溯技术的历史）

  • 起源：从人类掌握钻木取火开始，拉开文明序幕。
  • 古代重大发明：
    • 四大发明：造纸术、印刷术、指南针、火药
    • 其他：纺织、水利、建筑、武器制造等
  • 近代工业化：蒸汽机、电力、内燃机推动社会变革。
  • 现代信息化：计算机、互联网、人工智能重塑生活方式。

2. 技术发展的驱动力

需求驱动：人类为满足生存、安全、交往、效率等需求而不断创造技术。

例如：

  • 照明需求 → 火把 → 油灯 → 白炽灯 → LED → 智能照明
  • 通信需求 → 驿站 → 电报 → 电话 → 手机 → 5G/卫星互联网

3. 技术与人的关系（重点）

  1. 保护人：提供抵御自然侵害、疾病、危险的手段（如疫苗、安全头盔、心率监测手环）。
  2. 解放人：延长或替代人体器官功能，提高效率（如洗衣机解放双手，汽车拓展出行空间）。
  3. 发展人：促进智力、创造力、审美和价值观发展，实现自我价值（如编程、设计、工匠精神）。

4. 技术与其他系统的关系

  • 技术与社会：技术是推动社会发展和文明进步的主要动力之一。
  • 技术与自然：在利用和改造自然的同时，必须注重生态保护与可持续发展。

5. 展望技术的未来（任务二）

  • 绿色节能（如太阳能+LED一体化）
  • 智能化与生态联动（如全屋智能照明）
  • 人因健康导向（动态调光适配生理节律）
  • 文化与情感融合（用“光”讲述空间故事）
  • 3D打印、纳米技术、生物工程等前沿方向

三、典型教学案例

  • 照明技术演变：从火把→蜡烛→白炽灯→LED→“光纸”（3D打印微型LED）
  • 造纸技术对比：
    • 古法造纸：浸泡→捣浆→浇纸→晒纸（劳动强度大、周期长、污染高）
    • 现代造纸：自动化、材料多元、高效环保

四、学科核心素养关联

  • 技术意识：理解技术发展逻辑，形成理性技术观。
  • 创新设计：激发基于需求的创意构想。
  • 物化能力：通过技术体验（如古法造纸）培养动手实践能力。
  • 工程思维：分析技术演进中的优化与权衡（如成本、效率、环保）。
  • 社会责任：思考技术伦理与可持续发展。

五、学业考查要点（示例）

  • 单选题：某心率监测手环可自动提醒服药，体现技术可以（B. 保护人）。
  • 单选题：“大国工匠”实现自我价值，说明技术可以（B. 发展人）。
  • 简答题：举例说明技术如何“解放人”？
